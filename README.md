# Tip: Do Not Stare at the Build

A loading-screen tip for the exact audience stuck reading loading
screens: stressed developers and the AI agents pair-programming with
them. The advice is empirically sound — compilers, like cats and senior
engineers, only work when nobody is watching.

It lands because it is useless and true at the same time, which is the
highest honour a loading tip can earn: the build will finish when it
finishes, and the staring was never helping.

The program clears the contents of the output directory and writes the
tip to `entry.txt`, byte for byte, with no trailing newline.
